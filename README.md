### Analise de Conteúdo Bot

Envio de conteúdo de grupos para a ferramenta de moderação da OpenAI.

[Mais explicações e exemplos aqui](https://blog.gabrf.com/posts/OpenAIModeration/).

#### Configuração

Crie os arquivos `utils/bottoken.conf`, `utils/groups.conf` e `utils/openai.conf`, sendo o primeiro o token do bot, o segundo os IDs dos grupos em que o bot irá funcionar e o último o token de acesso à OpenAI.

Execute o bot.

```
python bot.py
```
